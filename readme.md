# 1. 프로젝트 개요

전면 유리 블랙박스에 들어갈 시스템 개발

사고 장면은 눈에 띄기 때문에 직접 블랙박스를 조작해 영상을 기록하면 되지만,  
주차 중이거나 차 안에 사람이 없을 경우에는 사고나 범죄가 발생해도 이를 인지하지 못해 영상이 저장되지 않을 수 있음

따라서 간단한 AI를 활용하여 주차 상황에서 범죄 및 사고 의심 장면을 인식하고 해당 구간을 별도로 저장하는 시스템 개발을 목표로 함

FGI 형식으로 GPT를 활용하여 진행함

---

# 2. 핵심 목표

- 불필요 영상 저장 최소화  
- 주차 중 범죄 / 의심 행동 자동 감지  
- 이벤트 중심 영상 관리 시스템 구축  
- 사용자 “중요 장면”만 확인  

---

# 3. 주요 기능

## 3.1 영상 처리 기능

- 전방 카메라 실시간 녹화  
- 이벤트 발생 시 -20초 ~ +20초 구간 저장  
- 이벤트 구간 클라우드 전송  
- 루프 녹화  
- 영상 저장 및 삭제 관리  

## 3.2 AI 기능

- 사람 객체 인식  
- 차량 주변 접근 인식  
- 급격한 모션 변화 감지  

---

# 4. 시스템 구조


Camera → 영상 입력
AI Engine → 객체 / 행동 분석 (파인튜닝 필요 검토)
Event Manager → 이벤트 생성
Storage → 영상 저장
User App → 영상 확인 / 설정
