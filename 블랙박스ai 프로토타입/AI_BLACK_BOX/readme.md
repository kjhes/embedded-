# 블랙박스 ai 프로토타입
## 개요
- 이 프로젝트는 움직이는 차 블랙박스에 넣기 전에 먼저
지상에서 작동이 되는지 구현하는 프로젝트

## 설계방법
| 구현 목적 | 구현 방법 | 설명 |
|---|---|---|
|하드웨어| `jeston nano` | NVDIA 에서 개발한 ai 임베디드 툴로 웬만한 컴퓨터 수준의 ai 연산이 가능하다 |
|소프트웨어| `python` | 전반적인 모듈 연결, api 연결, AI 모델 구현|
|비디오 분석| `open cv` | 이미지와 영상을 분석 하는 기술 라이브러리 |
| AI 모델(CNN) | `yolo` | 사람, 차량 감지, 동작 분석 ai claude 는 로컬 환경에서 구현이 불가능 하다 결론지어서 로컬환경에 맞는 yolo ai 로 변경 (변경사항 yolo 는 CNN 모델로 간단한 이미지 판단만 가능해 다른 llm 기반 ai 를 로컬 환경으로 추가하기 했음)|
| AI 모델(LLM)|`Qwen2.5`| Qwen2.5-VL-3B 4bit 버전을 로컬 리눅스 환경에 옮겨 실제 범죄행위에 대한 판단을 가능하게 만듬


## 시퀀스 

- 1.jeston nano 에 설치된 카메라가 특정 간격으로 프레임을 기록 
- 2.로컬 환경에서 yolo ai 가 움직임 여부 판단 
- 3.비디오 녹화 시작 and log 전송(lte 사용- X 통신기능은 나중에 구현하기로 일단 WIFI 기반 로그 전송만)
- 4.범죄 행위라면 경찰에 자동적으로 신고 (yolo ai 성능이 구현했을때 좋게 나왔을때 만 넣기 -> Qwen2.5 양자화 버전을 통해 판단 실험)
- 5.내부에 공유기를 설치해서 wifi 가 있다면 영상을 저장공간에서 꺼내 전송 or 휴대폰이 근처에 왔을때 wifi 없이 전송 (jeston orion nano 에 내장 wifi 기능 사용 -> 일단 WIFI 로그 전송 기능만 살려보기)
