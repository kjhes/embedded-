1. 프로젝트 개요

전면 유리 블랙박스에 들어갈 시스템 개발
사고 장면은 눈에 띄기 때문에 직접 블랙박스를 조작해 영상을 기록하면 되지만
주차중이거나 차 안에 사람이 없을 경우에는 사고나 범죄가 일어나도 그게 찍혔다는 사실을 소유자가 알지 못해 영상을 기록하지 못함
그러므로 아주 간단한 AI 를 사용해 주차시에 범죄나 사고가 일어나는 장면을 인식하고 따로 저장해 두는 시스템 개발을 목표로함

FGI 형식으로 GPT 를 사용해 진행함

2. 핵심 목표

불필요 영상 저장 최소화
주차 중 범죄/의심 행동 자동 감지
이벤트 중심 영상 관리 시스템 구축
사용자는 “중요 장면만” 따로 확인

3. 주요 기능
전방 카메라가 실시간 녹화를 할때 특정 사건 중심으로 -20 +20 초 정도의 녹화 정보를 클라우드로 전송
실시간으로 일어나는 이벤트를 인식하고 분류
루프 녹화
영상 저장 및 삭제 관리

AI 기능
사람 객체 인식
차량 주변 접근 인식
갑작스러운 모션 변화 인식 

4. 시스템 구조
Camera → 영상 입력
AI Engine → 객체/행동 분석 - (파인 튜닝이 필요?)
Event Manager → 이벤트 생성
Storage → 영상 저장
User App → 영상 확인/설정

5. UML 구성
본 프로젝트를 위한 다음 UML 다이어그램을 만들어보는 과정을 가짐
Use Case Diagram
→ 사용자 기능 및 시스템 기능 정의
Class Diagram
→ 블랙박스 내부 모듈 구조 설계
Sequence Diagram
→ AI 분석 및 이벤트 저장 흐름
Activity Diagram
→ 주차 모드 전체 동작 흐름
